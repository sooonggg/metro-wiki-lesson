# 捷運新手學堂：LLM Wiki 與教學 HTML 簡報

延續先前的通勤、捷運新手與雙語求助主題。閱讀至少五篇官方資料，建立可追溯的 Wiki，再做成適合第一次搭乘者的教學簡報。

## 成果入口

- `index.html`：Wiki 首頁與四個主題頁。
- `slides.html`：10 張教學投影片；支援上一頁／下一頁、鍵盤方向鍵、跳頁與三題情境練習。
- `sources.html`：5 篇資料的網址、日期、摘要、使用範圍。
- `workflow.html`：先討論後生成、流程、返回路徑、實際資料問題、反思與 AI 協作說明。
- `validation.html`：實際網頁檢查紀錄。

## 知識與資料

- `source-notes.json`：AI 實際閱讀官方正文後保存的來源筆記，非全文複製。
- `wiki.json`：整合後的知識條目，包含來源 ID 和相關頁連結。
- `lesson.json`：各頁的教學問題與需要讀取的 Wiki 條目 ID。
- `project-plan.json`：討論範圍、修改前後的流程與資料取得紀錄。
- `run-log.json`：建置時讀取的 Wiki 條目與各頁來源對照。

## 如何執行

網站是原生 HTML/CSS/JavaScript。開啟 `index.html` 即可閱讀，不需要 API key。

需重新生成時，使用 Python 3.10 以上：

```sh
python3 build.py
python3 check.py
python3 -m http.server 8766 --bind 127.0.0.1
```

公開版本中，建置程式會依 `source-notes.json`、`wiki.json` 與 `lesson.json` 重建同一目錄的 HTML。原始工作目錄使用 `sources/` 時則輸出到 `dist/`。重新建置不會自動重新查詢官方網站，應先實際核對資料再更新查核日期。

## Workflow

討論主題 → 取得資料 → 檢查正文與來源 → 整理 Wiki → 按教學問題查詢 Wiki → 核對事實與例外 → 生成 HTML → 操作檢查。

- 讀不到正文：回到資料取得，找文字版或替代來源。
- 說法無依據：回到 Wiki 與原文核對，再修改教材。
- 網頁有問題：修正受影響部分後重測。

實際 LLM 工作由使用者與 Codex 對話完成。Python 執行引用與結構檢查、讀取 Wiki 並輸出 HTML；網頁沒有在背景自行執行 LLM，也不提供即時交通資訊。

## AI 協作揭露

使用者提供主題方向與討論；Codex 協助官方資料閱讀、摘要、Wiki 組織、教學大綱、英文練習句、程式和操作檢查。英文是練習句，非官方翻譯。提交作業前，使用者應親自閱讀、理解與測試，再以自己的話補充心得；不把 AI 執行的檢查寫成自己手動完成。

## 維護原則

先讀來源正文，才加入來源筆記。每條交通事實都須帶有來源 ID；不自行編寫班次或未驗證路線。官方更新日與本次查核日分開記錄。新增內容時先更新 Wiki，再讓簡報引用 Wiki，並保留重要例外。實際規定以臺北捷運最新公告為準。
